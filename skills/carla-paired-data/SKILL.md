# CARLA 成对数据生产

用同一驾驶场景的五个 ego 控制条件，采集公共历史与各自动作后果。生产入口为 `scripts/pipeline.py`，运行库随包提供；外部需要 CARLA 0.9.16、对应地图、Python 依赖及 GPU。命令路径相对本 skill 根目录，工作记录由 `--output` 指定，最终按场景直接读取的数据由 `--dataset-output` 指定，两者分离。

## 按任务读取

- 运行、恢复或调试采集：读 [工作流](references/workflow.md)。默认路径为环境检查 → 托管服务 → 共同历史实测 → 分支计划确认 → 完整无图预检 → RGB/LiDAR → 验收发布（`run --stage all`）；该命令自动规划，无需先执行 `plan`。
- 扩大模板内随机性、参与者组合、个体行为参数或检查采样偏差：读 [联合随机生成](references/scene-randomization.md)。保存提案和拒绝分母，同景所有随机条件冻结。
- 设计模板内交互阶段、联合布局与动作时序、评估行为覆盖：读 [交互多样性](references/interaction-diversity.md)。设计分层必须和实测阶段分开报告；行人入区/穿越与预先冻结的三档步速交叉覆盖，不按实测响应筛除场景。
- 配置场景、解释验收或读取数据：读 [数据契约](references/data-contract.md)，其中集中定义模板、天气、动作语义、字段、阈值和划分规则。
- 修改实现：用 [代码索引](references/code-map.md) 定位文件，并运行工作流中的相关离线测试。

- RGB 重复性修复（天气私有随机流、稳定贴花排序和密集区域距离场合成）、原生库适用范围及重新验证条件：读 [渲染复现](references/render-reproducibility.md)。

## 原生候选、相遇校准与左转速度设计

新批次在分配行人地点前实测行人模型在两个方向的生成位置。相遇校准利用实测公共历史和动作速度包络，左转根据地图曲率设计接近速度及加速上限。证据位置、旧版本重放和验收边界见[候选与相遇校准](references/candidate-calibration.md)。

Town07 的密集植被距离场合成修复随托管入口生效。第 16、57 景各通过六分支 198 对 RGB，傍晚开发景第 22 景通过同动作 78 对，Town05 行人回归通过六分支 198 对。正式运行使用高质量 DFAO 并逐景验收原图。[渲染回放证据](references/render-reproducibility.md)

## 行人受阻与真实等待

行人过街需在共同历史、无图物理预检和六条传感器分支上对齐步行指令、下一帧原生回读和实测地面位移。持续下发步行指令却被挡住的候选拒收，正常等待和动作后接触分别记录。阈值和适用时段见[数据契约](references/data-contract.md#行人步行执行核验)。

## 实测相遇校准与动态汇入

新增实测共同历史相遇校准和 `observed-gap-merge-v1`，详见[交互多样性](references/interaction-diversity.md)。新功能完成24景原生验证，覆盖12模板、240对ego动作及144条公共历史；固定Town04汇入与Town05行人两景另通过396/396对RGB、20/20对ego动作，原生与视觉12条分支逐值等价。采集来源与只读报告修正版的兼容关系见[本轮资格与边界](references/encounter-merge-qualification.json)。7景汇入中4景有分支相关的对象运动，3景汇入车轨迹相同；没有原生早期取消/返回覆盖，不能把离线能力当作已发生反馈。校准目标达标、静止等待豁免、无数值目标三类必须分开报告；旧200景不追认新策略。

## 修改前随机化资格范围（2026-11-15）

12模板的新版随机化已通过36景独立物理验收（360/360对ego动作）。固定4景视觉中3景通过、1景在Town07近处植被区域RGB重复超限；原四景完整视觉资格未全部满足，失败景不封存。这是带已知视觉限制的功能更新，不能宣称渲染根因已解决或各模板均有完整视觉资格。逐景原门禁与阈值保持，现有200景不追认新分布；详见[本轮证据与边界](references/scene-randomization-qualification.json)。

## 必须保持的约束

- 同景各分支共享初态和 NPC 策略；NPC 只读取当前可观测状态及固定地图关系，不读取 ego 未来轨迹或分支标签。
- 新行人使用 `reactive_crossing_v4`，可在有完整审计证据的共同预热中自然起步；逐帧比较继续、加快、减速、停步与沿已走路径有限退让；详见 [行人反馈](references/pedestrian-feedback.md)。使用实测车辆和其他行人状态，同景冻结初态、路线与规则，允许干预后实际起步时刻不同。新 `yield_wait` 同时要求指定对象整个身体已清空冲突区和当前可通行；`stop_hold` 不因对方通过自动恢复。
- 五个非 QA 动作条件全部保留；`maintain_repeat` 仅作重复性检查。轨迹相似不等于可以删除动作条件。
- 新编译场景冻结 `five-effective-ego-actions-v1`：历史2秒、未来4秒不变；五动作全部10对须同时通过持续控制差异和实际运动差异门槛。失败整景保留证据并换候选，不删掉相似分支凑数。旧数据只按其原冻结契约解释。
- 在首次实测 t0 检查响应机会：行人从真实人行道自然起步，联合设计过街阶段、来车关系并预留至少1秒估计响应观察时间。估计不保证实际响应；逐对象报告全部10对车辆及行人响应，弱响应仍如实保存。
- 执行失败进入有限修正；正确等待、弱反应及有效干预后的碰撞可以作为结果保留。验收阈值在采集前冻结。
- 去重与划分以整组成对场景为单位；近重复初态及同初态天气版本不得跨训练/验证/测试集合。
- 区分规划、编译、物理预检和正式验收。源码、参数或离线测试通过不能替代新批次的实际物理与图像证据；报告真实验收数量和缺额。
