# 过街途中持续反馈

新编译场景使用 `reactive_crossing_v4`。v2/v3的原行为仍按冻结版本解释。过去2秒、未来4秒、五种有效ego动作、画质与原QA阈值保持不变。同景各分支冻结同一个行人模型、初态、路线和反馈参数，不按分支名指定行人响应。旧 `gap_acceptance_v1` 的起步后承诺沿路线前进语义保留；旧数据不升级为新策略证据。

## 决策与动作

v3/v4起步前以名义步速和加速度对剩余完整过街路径作逐时刻车身扫掠检查；同一辆车不会因为较晚到达已清空的车道而阻挡整个过街过程。所有原身体/谨慎余量保留，旧统一间隙仍记录作诊断。起步后每0.05秒读取车辆和其他行人的实测位置、方向、包围框、速度，比较继续、加快、减速、停步和沿既定路线退让五种选择。所有车辆参与，包括未列入初始冲突角色、后来驶入路径的车辆。

每种选择生成2.5秒短时运动估计：分别从实测速度和上一帧命令速度出发，并将两条估计路径之间的整个范围纳入身体风险检查，以考虑原生执行滞后。下一帧速度命令相对上一帧命令限幅，避免每次从滞后的实测速度起算而无法正常起步或换向；这不等于保证实际加速度。周围对象通常按当帧速度和姿态外推。v3/v4仅在实际观测后车制动、同一路线前车已停车、横向一致、停车余量足够且无变道路线时，使用当前减速度外推到停车；其余情况保留恒速风险判断。所有车辆仍参加扫掠检查。逐段连续扫掠检查防止快车在离散采样之间穿过而漏检。检查考虑身体尺寸、局部框偏移与旋转；与另一层道路有高度间隔的物体不自动算作阻挡。

优先保持有余量的前进。v4在正常前进出现谨慎范围风险时，先按当前实测车身判断是否仍在受威胁车道的入口侧：能在已有谨慎余量走廊外停下、且完整短时扫掠无身体风险时可停步；已经入区时，只有能沿已走路径退回、全对象扫掠无身体风险，且退回的预测清空时间不晚于同样无身体风险的向前加快清空时间，才优先退让。不能识别入口侧、已在出口侧或退回并不更合适时，继续比较加快、慢行及其他可行选择。退让和向前加快仍按最小身体余量比较预测清空时间；退让途中不会因刚越过身体边界就立即停驻，停驻另需达到既有谨慎余量。固定退让目标及最大后退额度不变，不能为取得余量反复刷新目标。这样不再固定把加快排在所有停步和退让之前。后方车辆和行人仍参与所有选择的扫掠检查；另一行人的朝向不解释为车道。

退让先减速至零再反向，通过原生 WalkerControl 的方向和速度移动，不修改演员变换、不瞬移。连续一次退让的目标固定，目标最多比触发时站位后退1.2米（制动期间可能继续前移，实际反向路程另报），不能退到原路线起点之外；中途暂停不会刷新后退额度。由停步/退让恢复为慢走或正常前进，以及由慢走恢复正常前进，都要求风险消退持续确认时间（默认0.4秒，新联合随机生成按景冻结0.3～0.55秒）；如果原来的等待/退让动作本身变得有风险，该确认时间不能阻止采取更合适的动作。

入口侧比较与风险检查共享实测速度/上一命令两条路径之间的完整AABB包络，以及周车当前速度和已证实制动的位移估计，包含横向运动。清空时间是预测网格上的首次持续离开车身走廊时刻，含制动和换向过程；不是实际避碰保证。`refuge_comparison` 保存每个相关对象的入口侧判断、余量和停步/退回/向前清空时间。该判断不读取模板阶段、ego动作名或未来控制。

新联合随机生成可按景冻结命令加速1.35～1.65m/s²、加快比例1.4～1.65及恢复确认0.3～0.55秒；其他范围和风险余量不变，规划起步时间同步使用该景加速值，详见[联合随机生成](scene-randomization.md)。以下为未覆盖时的默认值，实际重放始终读取 spec。

冻结默认参数：加快上限为名义速度的1.5倍且不超过2.5m/s；慢行速度为名义速度的50%，退让速度不超过0.8m/s及原名义速度；命令加速1.5m/s²、减速3m/s²；身体风险余量0.25米，谨慎余量0.75米。这些是显式工程模型参数，未做真人行为标定。实际速度、位移和接触必须读取原生记录，不能把命令值冒充实测。

## 证据与边界

v3/v4在退让终点或路线端点附近提前减速，位移不会直接钳回目标。如果实测运动已经越过目标，则按减速度限制停下；短暂惯性延伸纳入风险扫掠，并保存实际退让距离，不能宣称位置硬限幅。静止时不会因端点插值主动越界或瞬间反向。

v4使用 `pedestrian-decisions-v4`（旧v3仍使用自己的schema），逐帧保存五种选择的逐对象预测风险、最终模式、原因、策略状态和下一物理区间控制。`pedestrians.npz` 保存实际运动、已执行控制及下一步命令。末帧是未执行的零占位。离线验收从当帧数据及过去策略状态重算控制与决策，篡改状态、控制、事件摘要或缺失新源码身份均不能通过。

摘要单列命令模式转换、实测首次运动、运动后再次停步、实测反向路程。公共历史、同动作重复、物理/视觉重放继续检查；相关对象10对响应仍如实记录，不保证每个对象在五条ego分支下都不同，也不按响应是否丰富删除样本。

当前状态外推不预知车辆未来转向、加速或突然制动。无任何短时选择可避开预测冲突时，记录 `unavoidable_predicted_conflict`，先比较预测冲突到达时间，再比较冲突持续时间；时间差小于半个物理步视为同档，同档优先延续当前响应，避免几微秒的数值差异导致反复换向。这不代表已经安全；真实碰撞仍由原生传感器记录。地图上的静态障碍不是当前动态对象风险模型的输入，路线本身仍须通过地图设计和原生检查。新代码、离线测试与物理诊断不自动构成完整六相机/LiDAR视觉交付。

原生接口语义：[CARLA 0.9.16 WalkerControl / Walker.apply_control](https://carla.readthedocs.io/en/0.9.16/python_api/#carlawalkercontrol)。控制在下一tick执行，读回的control属于上一tick；退让使用反向单位向量和非负速度。
