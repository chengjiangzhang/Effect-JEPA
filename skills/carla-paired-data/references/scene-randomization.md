# 模板内联合随机生成

`joint-scene-randomization-v1` 使用12个模板约束主要交互，阶段配额控制计划覆盖，连续参数和参与者组合在阶段内采样。它是有界的工程生成分布，不是经标定的真实交通人口模型，也不是任意车辆数量、任意道路组织的生成器。

## 生成与冻结

1. 任务规划固定模板、风格中心、天气及交互阶段；候选失败后保留该槽位的配额。管线的 `catalog.json.cell_eligibility` 另记地图可行候选与预先排除原因，不把地图候选数混作场景尝试数。
2. 为每个候选生成并立即保存 `sampling_proposal.json`。`intent` 记录参数、参与者数量、种子、阶段和采样版本，编译失败也不丢失。独立编译的对应记录在 `compilation.json.sampling_proposals`。
3. 根据真实地图、车身、停车空间及固定4秒未来联合安排出生位置。保留请求值与最终生效值；不根据五条未来的对象反应选择初态或t0。
4. 在 `spec.json.randomization` 中冻结采样意图、个体偏好、实际参与者及最终编写参数。与原 `interaction_design`、`authoring_contract` 并列保存，不将设计进度冒充实测进度。
5. 运行共同预热与过去2秒，实测t0后确认动作计划；六条分支全部重新核对公共历史、控制器状态、repeat和原有质量门槛。

种子流按“版本、layout seed、参数名或角色名”独立派生。新增一辆次要车不会重抽已有对象的行为偏好、车型和颜色。物理约束仍可能改变可用布局，不能据此承诺不同参与者数量时运动不变。运行时不逐帧抽动作。

## 实际随机维度与边界

| 维度 | 当前实现 |
| --- | --- |
| 连续条件 | ego与主对象初速、前后间距、队列间距、相对速度、名义到达差、动作强度/介入时刻分别抽取；必要的停车与相遇联系通过联合布局保留 |
| 数量与组合 | 行人模板1～7辆车及1名主行人；其他模板2～7辆车，保留必要主对象。窄路两侧跟车数量分别变化；汇入可有或没有主路后车；道路背景车按可用真实路线选槽位 |
| 交互进度 | 横移开始时间、行人身体相对冲突区的距离、窄路对向进度及实际信号剩余时间连续变化。行人在真实人行道起步，经共同历史自然到达；不可在t0瞬移 |
| 个体偏好 | 以原三风格作为参数中心，各NPC的加速、舒适制动、时距、静止间距、冲突间隙、前瞻和目标速度分别变化；几何安全余量及QA阈值不变 |
| 行人偏好 | 步速、起步加速能力、恢复确认时间和加快比例变化；全部有限、同景固定。双向过街仅在实际映射人行道及观察距离可行时使用 |
| 外观与地点 | 使用现有真实地图候选和已支持车型，直路锚点可沿映射路线移动；车型/颜色使用独立流，天气仍在模板内均衡，不由行为结局决定 |

某些有信号几何的可行初速范围很窄：采样保留实际信号、停车空间和观察窗口约束，不能为了更随机而突破可行范围。已支持的路线组合来自地图候选和模板可用走廊，不额外宣称覆盖所有交叉来车、任意转向或多行人互动。

同景所有ego分支共享参与者、路线、个体参数、外观、天气、信号及公共历史。个体偏好可能无法从2秒图像完全识别，属于记录在GT中的隐藏条件，不直接证明模型忽略action。公共历史与repeat须实测一致，seed只是复现配置的工具。

让行和停车策略在强制保持零速时均声明足够的终端服务制动；让行的非零速度减速过程和已满足清空条件的滚动恢复仍由原规则控制。原生开发发现旧0.4驻车制动在部分随机速度下停得过慢；该修正不放宽驻车、停车位置或动作区分门槛。

## 分布、拒绝与实测统计

每次阶段结束生成一次 `randomization_report.json`，使用已有规格和数值报告，不重新采集、不重新扫描RGB。区分计划槽位、提案尝试、成功编译、拒绝、物理合格、完整视觉验收；修正次数和槽位数不得混算。中断后可显式运行：

```bash
python -B scripts/randomization_report.py --output /path/to/work --out /path/to/report.json
```

报告按模板及模板×阶段列出数量、速度/间距/时序分布、强线性相关提示、参与者/路线组合及拒绝原因；同时保留每次提案参数与最终状态，支持核查某个参数区域的失败倾向。相关系数是有限样本诊断，不是独立性证明；不同阶段混在一起的相关关系不能直接归因于错误绑定。

原生数据另报实测t0、反馈事件、阻挡条件和每对象全部10对响应。合格场景的五分支9个未来图像时刻轨迹以共同ego(t0)坐标保存摘要；只对模板、语义角色与动作集合可比的场景计算整段位置RMS，列出最相似场景。该诊断不证明交通等价，也不删除合法相同后果。

开发集可据此修正采样；正式评测开始前冻结分布、预算与门槛，之后如实报告缺额、等待、弱响应和有效干预后的接触。不要通过提高强响应比例筛选评测集。新代码通过离线/地图检查不等于已完成原生资格，也不追认现有200景为新分布。

## 本轮已验证范围

开发12景为source_003；独立36景为最终source_004，12模板×3风格各1景，360/360对ego动作及216条公共历史通过。固定视觉4景：匝道汇入、行人与夜间信号路口3景完整通过594/594对RGB；Town07窄路景37/78对重复图像超限，原失败保留，未替换或放宽阈值。因此原四景完整视觉协议未全部满足；本更新交付随机化功能及其明确限制，不将该失败景列为视觉合格。具体实测数量、来源版本、失败分母和限制见[资格记录](scene-randomization-qualification.json)。
